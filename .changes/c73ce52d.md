Latin text now uses Noto Sans. When the root element's lang is Chinese, Noto Sans SC stays first so quotation marks, ellipses and dashes keep their full-width form. The new --hn-font-latin and --hn-font-cjk tokens set the two parts of --hn-font-sans; load Noto Sans in the application to use it.
