# Hina UI

**优雅、克制的 Vue 3 组件库。**

组件覆盖排版、布局、浮层与页面骨架。由 [Reka UI](https://reka-ui.com) 和 [Tailwind CSS v4](https://tailwindcss.com) 驱动。

---

- **深色模式与紧凑模式** 在外层容器设置一个属性，整片界面随之切换，组件不必逐个适配。
- **外观可调** 颜色、圆角、动效时长都是 CSS 变量，覆盖变量即可自定义外观。
- **无障碍** 焦点管理、键盘操作与屏幕阅读器语义开箱即用。
- **排版与骨架齐全** 0原生标签快速搭建页面。

## 安装

```bash
pnpm add @hina-ui/vue
```

样式入口、字体与深色模式的接入方式见文档。
